# Treasure Hunters - Game Analysis

## Summary

A 10-turn set collection game where **player-2** achieved victory with 60 points through aggressive Type Set collection, outpacing player-1 who scored 30 points with 2 Type Sets.

## Winner

**player-2** - Score: 60 points (4 Type Sets)

## Win Condition

First player to reach **score >= 50** via set collection. Player-2 reached 60 points on turn 10.

## Key Moments

| Turn | Player | Action | Significance |
|------|--------|--------|--------------|
| 1 | player-2 | Collected Ring Type Set | Early 15-point lead, set aggressive pace |
| 4 | player-2 | Collected Goblet Type Set | Extended lead to 30 points |
| 4 | player-1 | Collected Crown Type Set | First set for player-1, playing catch-up |
| 7 | player-2 | Collected Crown Type Set | Built commanding 45-point lead |
| 10 | player-2 | Collected Ring Type Set | Victory - reached 60 points |

## Mechanics Observed

- **Set Collection**: Core mechanic - both players actively pursued Type Sets (3 cards of same type, different gems)
- **Resources (Gold)**: Income generated each turn but largely unused - players focused on drawing cards
- **Income**: 2 gold per turn for each player enabled consistent economy
- **Action Points**: 3 action points per turn structured decision-making

## Player Strategies

### player-1 (30 points, 2 sets)
- Cautious approach with more drawing and passing
- Collected Crown and Ring Type Sets
- Fell behind early and couldn't catch up

### player-2 (60 points, 4 sets)
- Aggressive set collection from turn 1
- Efficiently identified and completed matching sets
- Dominated with double the sets of opponent

## Recommendations

1. **Balance consideration**: The first player to collect a set gains significant momentum - consider reducing Type Set value from 15 to 12 points
2. **Resource utilization**: Gold accumulation was largely unused - consider adding compelling ways to spend resources
3. **Action point economy**: Drawing cards was the dominant strategy - consider making other actions more attractive
