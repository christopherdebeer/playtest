# Treasure Hunters v1.0 - Playtest Analysis

**Game ID:** treasure-hunters-1770035762715  
**Version:** 1.0  
**Winner:** player-1 (by resignation)  
**Final Score:** player-1: 45 points | player-2: 15 points  
**Duration:** 24 rounds, 48 turns  
**Date:** 2026-02-02

## Executive Summary

Player-1 won by resignation at turn 48 after establishing a commanding 30-point lead (45-15). The game showcased the core set-collection mechanics but revealed significant balance issues: excessive early-game card hoarding led to a slow start (no sets collected until turn 24), followed by an explosive endgame where Player-1 collected 3 sets in just 5 turns. The game ran 24 rounds despite a 30-round maximum, suggesting the 50-point win condition is difficult to reach through normal play.

## Game Flow Analysis

### Phase 1: Setup and Card Hoarding (Rounds 1-11, Turns 1-22)
Both players spent the opening largely drawing cards and playing minimal treasure cards. Neither player attempted set collection, focusing instead on building large hands:
- Turn 1: Player-1 played Diamond Goblet
- Turn 2: Player-2 played Diamond Crown  
- Turns 3-22: Almost exclusively drawing cards, with occasional treasure plays
- Both players hit max gold (20) by round 10

**Pattern:** Players prioritized hand size over tempo, treating the 3 AP/turn system as "draw until hand is full."

### Phase 2: First Set Collection (Rounds 12-20, Turns 23-40)
- **Turn 24 (Round 12):** Player-2 collected first set (Type Set: Sapphire/Emerald/Diamond Goblets) → 15 points
- Rounds 13-20: Both players continued drawing, building toward multiple sets simultaneously

### Phase 3: Player-1's Explosive Finish (Rounds 21-23, Turns 41-46)
Player-1 collected 3 sets in rapid succession:
- **Turn 41:** Color Set (Sapphire collection: Ring/Crown/Goblet) → 30 points total
- **Turn 43:** Color Set (Emerald collection: Ring/Crown/Goblet) → 45 points total  
- **Turn 45:** Type Set (Ring collection: Ruby/Diamond/Sapphire) → 60 points... wait, should be 45 + 15 = **45 points** (Player-2's resignation reason incorrectly stated 60)

### Phase 4: Resignation (Round 24, Turn 48)
Player-2 resigned citing "Player-1 has reached 60 points" (factually incorrect - Player-1 had 45). However, the strategic assessment was sound: Player-1 needed only 5 more points (1/3 of a set) while Player-2 needed 35 points (2+ sets).

## Key Observations

### What Worked Well

1. **Set Collection Mechanic**: The dual-path scoring (Color Sets vs Type Sets) provided meaningful strategic decisions when players finally engaged with it
2. **Action Point System**: The 3 AP/turn with varying costs (Draw=1, Collect Set=2) created resource tension
3. **Resource Caps**: Gold maxing at 20 prevented runaway accumulation
4. **Clean Win Condition**: First to 50 points was clear and achievable

### Critical Issues

1. **Draw Action Too Strong**: Both players spent 20+ turns just drawing cards with no penalty
   - No hand size limit mentioned in rules
   - Draw costs only 1 AP (same as playing a card)
   - Result: Degenerate "draw until you have perfect sets" strategy

2. **Lack of Early-Game Pressure**: No incentive to collect sets early
   - Income is automatic (2 gold/turn)
   - No tempo advantage for scoring first
   - Action cards (Treasure Map, Thief, etc.) were never played despite being drawn

3. **Set Collection Timing**: Collecting sets costs 2 AP (66% of turn), but provides no immediate benefit beyond points
   - Players hoarded cards until they had multiple sets ready
   - Then "cashed in" all at once (Player-1's turns 41-45)

4. **Player-2's Resignation Math Error**: Confusion about scoring suggests unclear in-game feedback
   - Stated "60 points" when Player-1 had 45
   - May indicate need for better score tracking/display

5. **Unused Mechanics**: 
   - Action cards were drawn but never played (Treasure Map, Merchant, Gem Finder, Thief)
   - Gems resource was never used (both players ended at 0 gems)
   - Gold capped at 20 but had no spending outlets used

## Strategic Patterns

### Player-1's Strategy (Winner)
- **Early:** Aggressive drawing (15 draw actions across turns 1-41)
- **Mid:** Built complete sets in hand before committing
- **Late:** "Burst" strategy - collected 3 sets in 5 turns once combos were ready
- **Result:** Dominated by optimizing set completion before collecting

### Player-2's Strategy (Resigned)
- **Early:** Similar draw-heavy approach (10+ draw actions)
- **Mid:** Collected first set (turn 24) but couldn't maintain momentum
- **Late:** Continued drawing but couldn't assemble additional sets before Player-1's burst
- **Result:** Lost tempo race despite scoring first

## Balance Recommendations

### Priority 1: Fix Draw Action Dominance
- **Add hand size limit** (e.g., 10 cards max)
- **Increase draw cost** to 2 AP, OR
- **Make sets collectable for 1 AP** to reward tempo
- **Discard phase**: Force discard to 7 cards at end of turn

### Priority 2: Create Early-Game Incentives
- **Milestone bonuses**: First set collected gains +5 bonus points
- **Momentum mechanic**: Collecting a set grants +1 AP next turn
- **Penalty for hoarding**: Lose 1 gold per turn if you don't collect a set for 5 consecutive turns

### Priority 3: Make Action Cards Relevant
- **Reduce cost** to 0 AP (play for free as part of another action)
- **Treasure Map**: Draw 3 cards instead of 2
- **Thief**: Make more disruptive (discard 2 cards, or prevent next set collection)
- **Gem Finder**: Give gems a purpose (spend 3 gems = collect set for free?)

### Priority 4: Improve Pacing
- **Reduce win condition** to 35-40 points (current 50 is too high - game took 24 rounds)
- **Or reduce points per set** to 10-12 instead of 15
- **Round limit**: Consider 20 rounds instead of 30 (game was decided by round 23)

## Recommended Next Version Changes

### v1.1 Priority Fixes

1. **Hand size limit: 10 cards** - Must discard at end of turn if over
2. **Collect Set cost: 1 AP** (down from 2) - Make scoring more appealing
3. **Draw cost: 2 AP** (up from 1) - Reduce draw-spam viability  
4. **Win condition: 35 points** (down from 50) - Faster games
5. **Action cards cost: 0 AP** - Play free during turn
6. **First set bonus: +5 points** - Reward tempo

### Test Goals for v1.1

- Target game length: 12-15 rounds
- At least 50% of action cards should be played
- Players should collect sets starting by round 5-7
- No player should draw more than 5 consecutive turns without collecting a set

## Conclusion

The game engine performed flawlessly with no bugs or crashes. However, the game design suffers from a critical imbalance: drawing cards is overvalued relative to playing them or collecting sets. This created a 22-turn stalemate where both players hoarded cards before Player-1's explosive 3-set burst sealed the game.

The core set-collection mechanic is sound and engaging when players interact with it, but the current costs and incentives push players toward degenerate "hoard and burst" strategies rather than interactive gameplay.

**Playability:** Currently C-tier (functional but not fun). With draw costs rebalanced and hand limits added, could easily reach A-tier.

**Recommendation:** Implement v1.1 fixes and re-playtest immediately. This game has strong potential with relatively minor balance adjustments.
