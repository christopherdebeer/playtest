**Date:** 2026-02-03

## Executive Summary

Player-1 achieved a decisive victory by reaching 60 points on turn 23, collecting 4 Type Sets for a total of 60 points. Player-2 managed only 1 set (15 points) throughout the game. The game demonstrated strong set collection mechanics but revealed significant balance concerns around card draw strategy and early momentum.

## Key Observations

### What Worked

1. **Action Point System** - The 3 AP per turn created meaningful decisions between drawing (1 AP) vs collecting sets (2 AP)
2. **Set Collection Scoring** - The 15 points per set created clear milestone targets
3. **Type vs Color Sets** - Both set types were viable (all 5 sets were Type Sets in this game)
4. **Card Draw as Primary Strategy** - Drawing 3 cards per turn (using all AP) proved to be the optimal early game strategy
5. **Win Condition Clarity** - First to 50 points was clear and achievable (winner reached 60)
6. **Income System** - Automatic +2 gold per turn kept resources flowing

### What Didn't Work

1. **Runaway Leader Problem** - Once player-1 completed their second set (turn 17), player-2 could not catch up
2. **Limited Interaction** - Only 1 Thief card was played (turn 8), and it had minimal impact on the outcome
3. **Action Card Underuse** - Only 3 action cards played total (1 Treasure Map by P1, 1 Merchant by P2, 1 Treasure Map by P2)
4. **Gold/Gem Resources Unused** - Both players reached 20 gold cap but had no reason to spend resources
5. **Set Completion Imbalance** - Player-1 collected 4 sets vs player-2's 1 set despite similar play patterns
6. **Color Sets Never Used** - All 5 collected sets were Type Sets, suggesting Color Sets may be harder to achieve

### Balance Findings

**Draw Strategy Dominance:**
- Player-1 drew aggressively (turns 1, 3, 5, 7, 9, 11, 15, 19) before collecting sets
- This "draw then collect" pattern proved superior to "draw incrementally"
- Player-2 drew more cautiously and fell behind

**Set Completion Rates:**
- Player-1: 4 sets in 23 turns (1 set every 5.75 turns)
- Player-2: 1 set in 23 turns (despite early lead)

**Resource Caps Hit:**
- Both players reached 20 gold maximum
- No gems were acquired (Gem Finder cards never played)
- Resources felt superfluous to core gameplay

**Action Card Usage:**
- Treasure Map (draw 2) was the most valuable action card
- Merchant (gain 3 gold) had no impact since gold was capped
- Thief forced 1 discard but didn't meaningfully slow player-1
- Gem Finder was never played (gems had no apparent use)

## Strategic Patterns

### Player-1 Strategy (Winner)
1. **Early Draw Phase** (Turns 1-11): Drew aggressively to build a large hand
2. **Collection Phase** (Turns 13-23): Collected 4 Type Sets in rapid succession
3. **Resource Management**: Capped gold but never needed to spend it
4. **Action Card Use**: Minimal (1 Treasure Map early for card advantage)

### Player-2 Strategy (Loser)
1. **Early Set Rush** (Turn 2): Collected first set immediately for early lead
2. **Maintenance Drawing** (Turns 4-22): Drew cards but never achieved critical mass
3. **Late Desperation** (Turn 22): Played Treasure Map when far behind (45-15)
4. **Interference**: Attempted 1 Thief play (turn 8) but insufficient disruption

## Critical Issues

1. **Resource System Broken** - Gold capped at 20 but had no spending opportunities (Spend action mentioned in rules but not implemented)
2. **Gems Purposeless** - No gem spending mechanisms observed; Gem Finder cards were dead weight
3. **Interference Too Weak** - Thief forced 1 discard but couldn't stop a player with 10+ cards
4. **Color Sets Too Hard** - Require 3 specific cards (same color, different types) vs Type Sets (same type, any 3 colors)
5. **No Comeback Mechanics** - Once behind 30-15, player-2 had no way to disrupt or catch up

## Recommendations for Next Version

### High Priority

1. **Add Resource Spending Options**
   - Allow gold to be spent for: re-draw actions, card cycling, or set bonuses
   - Create gem-based special abilities (e.g., "Spend 2 gems: Draw 3 cards and collect a set this turn")

2. **Balance Set Difficulty**
   - Reduce Color Set requirement to 3 cards (any type, same color) OR
   - Increase Color Set points to 20 while keeping Type Sets at 15

3. **Strengthen Interaction**
   - Add more interference cards (increase Thief count from 2 to 4)
   - Create blocking mechanics: "Prevent opponent from collecting sets this turn"
   - Add steal mechanics: "Take 1 card from opponent's hand"

4. **Implement Comeback Mechanics**
   - Trailing player bonus: Player with lowest score draws +1 card per turn
   - Milestone abilities: At 30 points, unlock special actions

5. **Clarify Resource Usage**
   - Document what "Spend" action does in rules
   - Create clear gold/gem sinks

### Medium Priority

6. **Adjust Action Costs**
   - Consider making draw 3 cards cost 2 AP (currently 3 × 1AP = 3AP, using entire turn)
   - This would force more interaction between drawing and other actions

7. **Add Deck Cycling**
   - With 48 cards in deck, add shuffle discard pile mechanism
   - Prevents deck depletion in longer games

8. **Victory Condition Tuning**
   - Consider reducing win threshold to 45 points (3 sets)
   - OR increase to 60 points but add catch-up mechanics

### Low Priority

9. **Add Action Card Variety**
   - "Saboteur" - Break up opponent's set
   - "Trader" - Exchange cards with opponent
   - "Fortune Teller" - Look at top 3 cards, take 1

10. **Track Incomplete Sets**
    - Visual indicator for "2/3 Color Set" progress
    - Creates tension around blocking opponent's visible progress

## Conclusion

Treasure Hunters demonstrates solid core mechanics (action points, set collection) but suffers from runaway leader issues and underutilized resource systems. The game feels like a race to build the biggest hand, then rapidly collect sets. Player interaction is minimal, and Color Sets appear significantly harder than Type Sets.

**Recommended Focus**: Strengthen player interaction, balance set difficulties, and give resources meaningful purposes. The foundation is strong but needs refinement to create competitive back-and-forth gameplay.

**Overall Grade: C+**  
*Functional but needs iteration on balance and interaction before broader playtesting.*
