## Recommendations for Next Version

### Priority Changes

1. **Add Spending Mechanics:**
   - Define what "Spend" action does (currently unclear)
   - Create gold/gem-powered abilities:
     - "Spend 5 gold: Draw 2 cards"
     - "Spend 3 gems: Swap a card from discard"
     - "Spend 10 gold: Steal a card from opponent's collection"

2. **Balance Treasure Map:**
   - **Option A:** Increase cost to 2 AP (same as collecting a set)
   - **Option B:** Reduce to +1 card draw
   - **Option C:** Add "Discard 1 card" cost to use

3. **Enhance Gem Value:**
   - Currently gems have no clear purpose beyond accumulation
   - Add gem-powered cards or abilities
   - Consider: "Spend 2 gems: Complete a partial set (if you have 2/3 cards)"

### Balance Adjustments

4. **Resource Caps:**
   - Lower gold cap from 20 to 15 (never reached 20)
   - Add incentive to spend before capping

5. **Action Card Variety:**
   - Add more action card types to compete with Treasure Map
   - Examples:
     - "Treasure Vault" - Gain 2 gold AND draw 1 card (2 AP)
     - "Second Wind" - Gain 2 additional AP this turn (costs 1 AP, net +1 AP)

### Rule Clarifications

6. **Clarify Spending:**
   - Rules mention "Spend" action (1 AP) but no spending examples
   - Add clear table of what resources can buy

7. **Thief Card Timing:**
   - Rules say "force opponent to discard 1 card" but doesn't specify when/how
   - Clarify: Does victim choose which card? Random discard? At what phase?

8. **Set Uniqueness:**
   - Can players collect the same set twice? (e.g., Ruby Color Set multiple times)
   - Game log shows player-1 collecting Ruby Color Set on turns 17 AND 39
   - Clarify if this is intended or if sets should be unique

## Conclusion

Treasure Hunters v1.0 demonstrates a solid foundation for a set collection game. The action point system and set collection mechanics work well together, creating an engaging core gameplay loop. Player-1's victory through superior card advantage (via Treasure Map optimization) shows clear strategic depth.

However, the game suffers from underutilized resource mechanics and potential card imbalance. The gold and gem systems need more spending outlets to justify their existence, and Treasure Map's efficiency may need adjustment to diversify strategic options.

**Recommended for next version:**
1. Define and implement resource spending mechanics
2. Balance Treasure Map efficiency
3. Add more action card variety
4. Enhance gem utility

With these improvements, Treasure Hunters could evolve from a functional set collection game into a rich strategic experience with multiple viable paths to victory.
